# founders-kit — FoundryAI for Claude Code

The Claude Code plugin build of [FoundryAI](https://github.com/VenkataAnilKumar/FoundryAI): 58 specialist agents, 9 team coordinators and 54 skills for AI startups.

```
/plugin marketplace add VenkataAnilKumar/FoundryAI
/plugin install founders-kit@foundryai
```

Plugin skills are namespaced, e.g. `/founders-kit:cofounder "build a RAG-powered document search"`.

**Don't edit `agents/` or `skills/` here** — they're generated from the repo's `agents/` and `skills/` by `scripts/build.py`. Using Cursor, Copilot, Codex or Gemini CLI instead? Run the repo's `install.sh`.
