FAQ

Does FoundryAI send my code or data anywhere?

No. FoundryAI is prompt files — agents, skills and templates. Your AI workspace runs them with whatever model and data settings you already use.

What does it cost?

Nothing. It's MIT-licensed. You pay your AI workspace or model provider as usual.

My workspace can't run subagents.

Everything still works: coordinators name the right specialist and, if you ask, take on that role themselves.

Is it only for AI startups?

It's tuned for AI startups — LLM apps, agents, devtools, voice, vision, generative media, robotics, model training and regulated verticals — but most of the engineering, product and growth specialists are useful to any software team.

How do I contribute an agent or skill?

Write it once in the neutral format and run scripts/validate.sh. See CONTRIBUTING.md on GitHub.
